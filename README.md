# 公路声屏障立面设计与实训考核系统

面向交通职业院校道路与桥梁工程专业的实训考核平台:**SolidJS + WebGPU**(WebGPU 不可用时自动降级 Canvas2D)。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 生产构建
```

演示环境免密登录,内置 1 名教师(王老师)与 3 名学员账号,数据存于浏览器 localStorage。

## 功能流程

1. **题库**(教师):设定桩号范围、屏体总高限值、立柱间距区间、透明屏比例下限、降噪要求与基准种子,并可把题目布置给学员生成任务。
2. **任务**:学员领取任务进入设计工作台;教师查看全部任务状态。
3. **设计工作台**(学员):
   - 填写生成参数(立柱间距/基准屏高/透明屏目标比例/吸声板规格/弧形矢高/种子),按规则过程式生成立柱、金属吸声板、透明屏与顶部弧形板的立面排布;
   - **同一套参数 + 同一种子 → 生成结果完全一致**(FNV-1a 派生种子 + mulberry32);
   - 点击任意跨可手动改高度、换板材、插装饰缝、调立柱位置,改动跨自动打 🔒 锁定标记;重新生成时锁定跨原样保留、其余跨按种子重算;
   - 实时检查:高度超限、立柱间距区间、透明屏占比、跨数与桩号核算、降噪量估算,违规处在立面上红色高亮并说明原因。
4. **提交**:自动评出合规分(按违规扣分)与参数分(参数与题目条件匹配度),记录全部修改历史。
5. **教师复核**:立面大图逐跨批注,给主观分与评语,按 合规40% + 参数30% + 主观30% 合成总成绩。
6. **成绩**:学员看本人、教师看全部。
7. **班级看板**(教师):错题(违规)按考点汇总,支持按班级筛选,含学员维度统计。

共 8 个界面:登录、题库、任务、设计工作台、提交详情、教师复核、成绩、班级看板。

## 结构

```
src/
  core/    prng(确定性随机) · generate(过程式生成) · validate(合规检查) · scoring(评分) · stake(桩号)
  gpu/     renderer(WebGPU/Canvas2D) · scene(立面场景构建)
  store/   db(localStorage 数据层) · session(登录会话)
  pages/   8 个界面
test/      smoke.ts 核心逻辑冒烟测试
```
