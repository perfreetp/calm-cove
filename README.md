# 车辆段检修库 · 照明布光与图纸质检系统

面向有轨电车车辆段检修库的照明设计工作台：设计员在二维平面上布灯、实时查看多光源叠加照度；
图纸提交后进入质检批次，由复核员按四项检查逐条确认 / 驳回，执行「严重问题整批退回、全部通过才放行出版」。

技术栈：React 18 + SVG + D3（等照度线 / 颜色标度）+ Vite，纯前端，数据保存在 localStorage。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物
```

## 功能结构

### 一、布光工作台（设计员）

**库房与图元**
- 4 线检修库 84 × 36 m、净高 9.5 m；四条检修地沟（−1.5 m）、三条纵向检修通道、端头主通道、
  12 根结构柱、3 处检修平台（+1.1 m）、1 处车顶作业平台（+3.2 m）、2 处配电柜。
- 库房长 / 宽 / 净高可在左栏直接修改，照度与热力图随之重算。
- 「按阵列布灯」可按行列数一键生成规则阵列，或「清空重排」。

**灯具**
- 5 种型号（HB-150 / HB-200 / HB-100N 窄配光 / LN-80 线槽 / EM-40 应急），
  余弦幂次配光模型 `I(γ) = I₀·cosⁿγ`，`I₀` 由光通量对半球积分反解。
- 单灯属性：型号、安装高度（2 m ~ 净高）、倾角（绕 x 轴 −75°~75°）、
  色温（3000 / 4000 / 5000 / 6500 K）、回路、应急 / 蓄电池标记。
- 画布上可直接拖动灯具（0.25 m 吸附，拖动时按帧节流重算）、
  「布灯」模式点击空白新增、`Del` 删除选中灯具。

**照度计算（二维平面 + 高程遮挡）**
- 网格 1 / 0.75 / 0.5 / 0.25 m 可选，默认 0.5 m；`E = Σ I(γ)·cosθ / d² · v`。
- 遮挡用解析阴影投影，逐灯预计算，避免逐格做三维求交：
  - 低于灯高的实体（立柱、机柜、检修平台）→ 顶面以灯点为中心相似放大投影到地面，
    放大系数 `s = h / (h − z_top)`，内区全遮、外扩半影区透光 0.55，形成软阴影；
  - 顶面高于灯高的结构 → 灯点向轮廓张开的二维锥形阴影；
  - 地沟 → 沟底采样点只接受经由沟口进入的直射光（沟壁遮挡），未进沟的光按 6% 残光计；
  - 沿墙 0.75 m 属墙区，柱 / 柜 / 平台占位不计入工作面统计。
- **软阴影渲染**：单独生成 `shadow` 因子图（被遮挡直射光占比），
  经高斯模糊叠到热力图上，可独立开关。
- **色温**只改变色度不改变照度：按 CCT 权重累加每格色调，热力图带轻微色温染色。

**时段工况**
| 工况 | 天然光本底 | 人工照明功率 | 说明 |
|---|---|---|---|
| 白天 | 210 lx | 35% | 天窗采光，光柱投影 |
| 黄昏 | 42 lx | 72% | 余晖侧向染色 |
| 夜间 | 4 lx | 100% | 仅人工照明（质检基准工况） |
| 检修 | 2 lx | 100% | 应急灯切满功率 |

**可视化**
- 热力图（canvas 逐格 → SVG image，D3 色标 0–1100 lx）
- 等照度线（`d3.contours`，150 lx 线加粗虚线）
- 遮挡软阴影、暗区标注、灯具 / 图元标注、逐格照度数值（放大后显示）
- 暗区按 4 邻域连通聚类，仅对成片暗区（≥6 格）打标签，并区分「地面 / 地沟 / 平台下」
- 悬停读数：照度、坐标、是否暗区、是否地沟、最近灯具与距离
- 滚轮缩放、`Shift`+拖动平移、比例尺、指北针、缩放自适应标注

**实时统计**
- 平均 / 最小照度、均匀度 U₀、暗区数量、最大 UGR、应急覆盖率
- 分区照度（4 条检修线分区）、地沟工作面、全库工作面
- 暗区清单：编号、类型、最小 / 平均照度、质心与四角坐标，点击可在图上定位
- 导出：照度网格 CSV、暗区清单 CSV

### 二、质检批次（复核员）

**四项检查**（提交时冻结结果与问题清单）
1. **灯具间距**：最近邻间距 ≤ 1.6H、阵列偏差 ≤ 1.8、最小间距 ≥ 1.4 m、安装高度不触屋面
2. **检修通道照度**：平均 ≥ 150 lx、均匀度 U₀ ≥ 0.40
3. **应急回路覆盖**：疏散路径 ≥ 3 lx、覆盖率 ≥ 95%、双回路、地沟应急照度
4. **眩光指数**：Guth 模型 `UGR = 8·lg(0.25/Lb · Σ L²Ω/p²)`，检修作业 ≤ 22

问题分 **严重 / 一般 / 建议** 三级，每条带定位坐标，可在平面图上高亮。

**复核流程**
- 逐条「确认属实」或「驳回」；**驳回必须填写不少于 6 字的理由**，否则拦截提交
- 确认属实后可标记「已整改」（一般 / 建议级）
- **任一项严重问题确认属实 → 整批自动退回设计方**，退回次数 +1，版本锁定
- 全部问题逐条闭环且无确认的严重问题 → 状态「待放行」，可 **放行出版**
- 多版本批次可切换 v1 / v2 查看各版本判定，退回记录随版本保存

**批次列表**
- 每套图显示：检查通过率（进度条）、退回次数、当前处理人、问题统计、状态、提交时间
- 状态：待复核 / 复核中 / 已退回 / 待放行 / 已放行
- 可新建批次；「提交图纸至质检批次」支持追加到已有批次或新建
- 导出质检报告 Markdown

### 三、方案比照

- 同一库房 2–4 套方案并排显示照度热力图，统一色标与工况
- 每套方案：平均 / 最小照度、暗区数、最大 UGR、均匀度、应急覆盖、严重问题数、灯具数
- 底部差值对照表：相对首套方案的平均照度增减

## 已知边界

- 照度为二维简化模型：不考虑顶棚与墙面反射（无利用系数法 / 辐照度法修正）、
  灯具为余弦幂次配光近似、UGR 为 Guth 模型简化实现，结果用于方案比选与图纸预检，
  不作为照度检测报告的依据。
- 遮挡采用解析投影（矩形 / 圆 / 锥形），非逐光线追踪；半影宽度按固定外扩量给出。
- 单一库房、固定图元拓扑；库房尺寸可调，但地沟 / 柱网位置不随尺寸自适应。
