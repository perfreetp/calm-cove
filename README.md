# 血站采血操作规范骨骼动画教学考核系统

基于 **SolidJS + WebGPU** 的骨骼动画教学与考核平台。质控科教师把采血流程拆成五个动作节点布置给学员,学员在编辑器中完成护士角色的分层绑骨、关键帧动画制作,系统自动校验规范区间并评分,教师回放复核后给出最终成绩与逐段评语。

## 功能全景

### 学员端
- **分层角色拆件导入**:支持多选导入 PNG 分层图(躯干/上臂/前臂/手掌/头部),也可直接使用内置程序化生成的护士拆件。
- **拖拽绑骨**:把拆件从左侧面板拖到视口的关节点上即完成绑骨;可在检查器调整锚点(pivot)、层级(zOrder)与绑定关系。
- **骨骼层级与关节限位**:树形展示躯干→头部/上臂→前臂→手掌的父子层级,可改父骨骼(带防环校验)、设置每根骨骼的最小/最大旋转角。
- **时间轴关键帧动画**:
  - 播放头打点,每段关键帧支持 **线性 / 缓入缓出 / 自定义贝塞尔(cubic-bezier 四控制点)** 三种缓动。
  - 关键帧菱形可拖拽改时间,点击后可精确编辑时间、数值、缓动与贝塞尔控制点。
  - 五个动作节点泳道可拖拽边缘调整时间区间。
- **规范实时校验与标红**:
  - 消毒动作 **不少于 30 秒**;
  - 进针角度 **15°~30°**;
  - 拔针后按压 **满 3 分钟(180 秒)**、按压力度 2~4 级;
  - 关节越限、节点顺序颠倒、内容缺失同样检出。
  - 所有违规区间在时间轴上以红色斜纹泳道标红,播放到该时刻视口左下角弹出违规提示。
- **WebGPU 实时骨骼形变预览**:WGSL 着色器做层级旋转 + 纹理采样;浏览器不支持 WebGPU 时自动回退 Canvas2D。
- **PNG 序列帧导出**:按自定义分辨率/帧率/时间区间逐帧离屏渲染,手写 PNG + ZIP 编码器打包下载(零第三方依赖)。
- **提交与退回整改**:提交即自动评分进入「待复核」;被退回后可查看**具体哪一段不合格、违规时间区间与教师评语**,整改后重新提交。

### 教师端(质控科)
- **待复核队列**:查看所有提交及自动分、违规数、退回次数。
- **回放复核工作台**:WebGPU 回放学员动画与时间轴,逐节点查看自动分明细(时长/指标/关节三维度)与违规定位。
- **逐段扣分与评语**:每个动作节点可独立给分(留空则沿用自动分)、写评语、标记合格/不合格;总评后可「完成复核」或「退回整改」(退回强制要求填写不合格段评语)。
- **成绩单汇总**:每个学员五个动作节点的得分矩阵 + 自动总分 + 最终成绩 + 状态。
- **全班错题 TOP3**:按违规人次聚合,统计出错最多的三个动作及违规类型分布。
- **标准课件库**:内置一份满分示范课件;学员的合格作品可另存为课件,所有课件可一键套用到编辑器复用。

### 评分状态机
`待提交(pending) → 待复核(reviewing) → 已完成(completed)`,复核不通过则 `已退回(returned)`,学员整改后重新回到待复核流程。

## 规范区间(系统判定依据)

| 动作节点 | 时长要求 | 指标区间 |
| --- | --- | --- |
| 1. 消毒 | ≥ 30s | — |
| 2. 进针 | 2~15s | 进针角度 15°~30° |
| 3. 固定 | 10~120s | — |
| 4. 拔针 | 1~10s | — |
| 5. 按压 | ≥ 180s | 按压力度 2~4 级 |

## 自动评分模型

每个动作节点满分 100,由三部分构成:

- **时长分(40)**:实际时长相对规范上下限的满足度;
- **指标分(35)**:节点区间内指标采样点落在规范区间的时间占比;
- **关节分(25)**:各骨骼采样角度落在 min/max 限位内的占比。

存在动作缺失(coverage)或顺序错误(order)的节点总分封顶 60。节点均分为作业总分。违规检测以 0.5s 为步长采样,合并为连续违规区间供时间轴标红与回放定位。

## 技术架构

```
src/
├── types.ts                 # 全部领域模型(骨骼/拆件/关键帧/提交/评分…)
├── data/constants.ts        # 五节点规范、指标、默认骨架/拆件、满分课件模板
├── lib/
│   ├── animation.ts         # 缓动(线性/缓入缓出/贝塞尔)、轨道采样、正运动学(FK)
│   ├── rules.ts             # 违规检测 + 自动评分 + 全班错题聚合
│   ├── scene.ts             # 骨骼位姿 → 渲染原语(quad/线/文字),双渲染器共用
│   └── export.ts            # 离屏逐帧渲染 + PNG 序列帧打包
├── renderer/
│   ├── renderer.ts          # WebGPU(WGSL)渲染器 + Canvas2D 回退 + 离屏渲染器
│   ├── textures.ts          # 内置护士拆件程序化贴图
│   └── encoder.ts           # 手写 PNG(stored deflate)/ ZIP(STORE)编码器
├── store/
│   ├── app.ts               # 全局状态:角色/作业/提交/课件/成绩单(localStorage 持久化)
│   ├── editor.ts            # 编辑器状态:文档、播放循环、关键帧/骨骼/拆件操作
│   ├── persistence.ts       # localStorage 封装
│   └── seed.ts              # 演示种子数据(含典型错误作业)
└── components/              # SolidJS 视图(视口/时间轴/检查器/绑骨面板/复核台…)
```

### 关键设计
- **骨骼动画模型**:所有骨骼静息角为 0(部件贴图竖直),关键帧存局部旋转量,正运动学沿父子层级累加世界角;子关节原点用父世界旋转矩阵换算。超限位姿态在着色器中标红并自动钳制。
- **双渲染器同源**:`scene.ts` 输出与后端无关的渲染原语,WebGPU 与 Canvas2D(及离屏导出)消费同一份场景数据,保证预览与导出一致。
- **零依赖二进制编码**:PNG 用 stored-block deflate + CRC32/Adler32,ZIP 用 STORE 方式小端打包,序列帧导出不需要任何第三方库。

## 运行与测试

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run build      # 生产构建
npm run typecheck  # TypeScript 严格检查
npm run test:rules # 规则引擎单元测试(15 项:规范判定/缓动/FK/评分/错题聚合)
```

端到端冒烟测试需要先启动 dev server,再以远程调试模式启动 Chrome/Edge,然后运行:

```bash
npm run dev &
# Chrome: --headless=new --remote-debugging-port=9222 --enable-unsafe-webgpu
npm run test:e2e   # 25 项:编辑器/绑骨/时间轴/评分/提交-退回-反馈/PNG-ZIP 导出全流程
```

> 提示:无头 Chrome 的截图不合成 WebGPU canvas 是其已知限制,不代表渲染失败;项目通过 GPU 纹理回读(readback)与 Canvas2D 离屏渲染两条路径验证像素正确性。正常有界面浏览器中 WebGPU 画面直接可见。

## 演示数据

系统首次打开自动写入种子数据:5 名学员、1 份考核作业、1 份满分标准课件,以及两份示例提交——一份含消毒时长不足、进针角度越界、关节越限、按压不足的典型错误作业(待复核),一份教师已复核完成的作业。教师端「重置演示数据」可随时还原。
