# 山舍体素 · 山区民宿改造体素建模与项目交付系统

Vue 3 + 原生 WebGL2（无 Three.js），Vite 构建，localStorage 持久化，无需后端。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```

## 8 个界面

| 路由 | 界面 | 说明 |
|---|---|---|
| /projects | 项目列表 / 客户下单 | 录房型、面积、预算、交付日期、用途；逾期标红并显示剩余天数 |
| /projects/:id | 项目详情 | 房间与任务管理、进度、全部通过后打包交付 |
| /tasks | 任务大厅 | 制作员按房间或镜头领取任务 |
| /editor/:taskId | 体素建模器 | 按层编辑、X/Z 轴镜像分别开关、框选复制粘贴（保留材质编号、跨房间）、按材质分块合并网格、超 8 万面自动简化并提示前后面数、导出 glb 与体素 JSON |
| /review | 主管审核 | 比例 / 门窗位置 / 通道宽度 / 预算四项核对，打回记返工次数 |
| /compare | 版本比对 | 同一房间历史版本并排渲染，统计新增/删除/材质变更体素数 |
| /delivery | 交付中心 | 客户只读查看进度与已交付版本，可下载 glb / JSON |
| /dashboard | 工作台 | 各制作员在手项数、平均返工次数、准时交付率；逾期项目汇总 |

## 角色

顶栏切换：客户（下单、看进度）/ 制作员（领取、建模、提交）/ 主管（审核、交付）。

## 流程

客户下单建项目 → 每个房间自动生成建模任务（可追加镜头任务）→ 制作员领取并在建模器编辑 →
提交主管审核 → 四项核对通过或打回（记返工）→ 项目所有项通过后打包交付 → 客户在交付中心查看。

## 体素引擎（src/voxel/）

- `model.js` — 40×20×40 体素网格、镜像写入、选区复制粘贴、版本 diff
- `mesher.js` — 朴素面剔除 + 贪婪合并两级网格化，按材质分块；超 8 万面先贪婪合并、仍超限则 2× 降采样，返回简化前后面数
- `renderer.js` — WebGL2 渲染器：轨道相机、层平面、选区/光标线框、射线拾取（层平面求交 + DDA）
- `glb.js` — 极简 GLB 导出（每材质块一个 primitive）
