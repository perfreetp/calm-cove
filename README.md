# 助产动画工坊 · MMS

面向**母婴护理培训机构**与**动画外包团队**的助产培训 2D 角色骨骼动画制作与交付系统。
整机为纯前端应用：SolidJS + TypeScript + WebGPU（不可用时自动回退 Canvas2D），
数据保存在浏览器 localStorage，可导出 / 导入整份项目存档。

## 跑起来

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 75 个单元测试
npm run typecheck
npm run build
```

首次打开会生成 3 个示例项目、8 个镜头与 6 个动作库条目，可直接点开体验完整流程。

## 主要流程

### 1. 立项（项目 → 新建立项）
录入课程名、客户、**交片日期**、**分辨率要求**、帧率与骨骼模板，并按行填写**镜头清单**
（镜头号 / 名称 / 时长）。保存后每条镜头自动生成一个独立制作条目。

项目列表按剩余天数排序，**超期**用红色「超期预警」标记，3 天内到期显示「临期」。

### 2. 制作（动画编辑器）
三栏 + 时间轴布局：

- **左栏**：部件分组树与骨骼层级。胎儿、骨盆、产道被拆成独立部件（胎头、躯干、四肢、
  骶骨、耻骨、坐骨、子宫体、宫颈……），每块部件绑定一根骨骼；可隐藏部件、折叠分组。
- **画布**：WebGPU 渲染。拖动模式可切换：
  - **旋转骨骼**：拖着骨骼手柄旋转，实时显示关节活动角度扇形。
  - **旋转中心**：直接拖动关节位置（即骨骼 pivot），0.5px 吸附。
  - 骨骼角度超出 `minAngle~maxAngle` 时该骨骼整体变红、画布底部红条提示、左树出现红点，
    并且**保存与提交都会被阻止**。Alt/中键拖拽平移，Ctrl+滚轮缩放，Ctrl+0 重置视图。
- **右栏检查器**：骨骼名称、父骨骼（自动排除会成环的候选）、旋转中心坐标、关节活动角度、
  当前帧旋转/位移、打关键帧、关键帧列表与**插值曲线**：
  - 线性 / 缓入缓出 / 自定义贝塞尔（可直接拖动两个控制手柄，X 轴锁定 0~1，Y 轴允许轻微过冲）。
- **时间轴**：按秒刻度，逐骨骼轨道，菱形关键帧按 fps 吸附拖动；不同缓动在区间条上着色
  （灰=线性，绿=缓入缓出，紫=贝塞尔）。播放/暂停、逐帧步进、循环、FPS 切换。

快捷键：`空格` 播放/暂停，`←/→` 逐帧（`Shift` 跳一秒），`K` 在当前时刻打关键帧，`Ctrl+S` 保存。

### 3. 复制动作到下一镜头
工具栏「复制到下一镜头」把当前镜头**全部关键帧与动作引用**复制到同一项目的下一镜头并跳转过去，
接着微调即可。两个镜头模板不同时会明确拒绝。

### 4. 提交与审核
制作员「提交审核」后镜头进入 `待审核`。审核页：

- 逐帧播放、逐帧步进、帧条上标出有意见的帧；
- 在任意帧写退回意见，可累积多条；
- **退回返工**：返工次数 +1，记录本次退回时间，并写入活动记录；
- **通过并锁版**：版本号 +1，画面与动作数据冻结，进入交付。

审核页可切换半透明骨骼层，方便核对关节角度。

### 5. 交付打包
「交付打包」中，已通过的镜头可一键 **打包并下载 ZIP**：

```
frames/S01_0000.png … S01_0119.png     真实渲染的 PNG 序列帧（按项目分辨率）
data/S01.action.json                   动作数据（MMS-ACTION-1）
manifest.json                          交付清单（MMS-SEQ-1）
README.txt                             说明与目录结构
```

序列帧由应用内光栅器逐帧绘制（无需 DOM canvas），动作数据包含骨骼层级、关节活动角度范围、
逐骨骼关键帧与缓动定义。每次可重新下载锁定版本的包，内容不会受后续修改影响。

### 6. 学员端回放
只读浏览已通过 / 已交付的镜头：播放、逐帧、速度倍率，以及**半透明骨骼层**与正常画面切换。
未通过审核的镜头在学员端不可见。

### 7. 动作库
动作（俯屈、内旋转、仰伸、复位、骨盆摆动、宫颈扩张）可被**多个镜头引用**。
修改动作的插值时，会先弹出**受影响的镜头清单**（含状态与「已通过，需重新审核」提示），
确认后才会重新烘焙这些镜头的关键帧，并记入活动记录。

## 代码结构

```
src/
  core/          纯逻辑（无 DOM，全部有单元测试）
    types.ts       领域模型
    skeleton.ts    骨骼拓扑、局部/世界变换、父子层级
    animation.ts   关键帧采样、增删改、区间切片与偏移
    easing.ts      线性 / 缓入缓出 / 自定义三次贝塞尔（牛顿迭代 + 二分回退）
    scene.ts       按时间生成可绘制的场景与骨骼辅助数据
    validation.ts  关节超限 / 环引用 / 悬空骨骼校验
    workflow.ts    提交、退回、通过、交付的状态机与到期计算
    delivery.ts    快照、清单、ZIP 打包
    templates.ts   胎儿 / 骨盆 / 产道 / 全景四套骨骼模板与自动构图
  render/        渲染层
    drawlist.ts    场景 → 三角化顶点（填充 + 描边 + 虚线）
    renderer.ts    WebGPU 管线，失败自动回退 Canvas2D
    png.ts         手写 PNG 编码器
    raster.ts      纯 JS 光栅器（导出序列帧用）
  components/    Stage（画布）、Timeline、Inspector、RigTree、BezierEditor、ui
  pages/         项目、项目详情、编辑器、审核、动作库、交付、学员端、活动记录
  store.ts       Solid store + localStorage 持久化
```

## 说明

- 渲染后端在画布左上角实时显示（`WebGPU` / `Canvas2D 回退`）。
- 所有关节角度均为**相对中立姿势**的角度，正值与负值的方向由骨骼的中立朝向决定。
- 数据存于 `localStorage['mms.state.v1']`；清空浏览器数据会重新生成示例项目。
