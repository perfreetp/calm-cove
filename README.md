# 口腔诊所牙列体素建模与打印批次质检系统

基于 **Svelte + three.js + Express** 的牙列体素建模与打印批次质检系统。

## 启动

```bash
npm install
npm run dev        # 同时起后端(3001)和前端(5173)
# 或分开：npm run server / npm run client
```

打开 http://localhost:5173 ，右上角切换四个角色：**修复科技师 / 复核员 / 医生 / 外协方**。

## 业务流程

1. **医生** 开口扫单（患者、牙位 FDI、修复类型、材料），可在医生端查看自己单子的进度与放行结果。
2. **技师** 在技师端选择订单与牙位，进入体素编辑器建模：
   - 分层查看/编辑：牙冠、牙龈、邻牙（邻牙仅参考，不参与打印实体）
   - 画笔尺寸可调（0.5–6 体素），左键增、右键减，拖动旋转视角
   - 开启「左右镜像」后绕中线对称编辑（同名牙对称，如 11↔21）
   - 「框选」工具点两点定义选区 → 复制 → 切换到其他牙位 → 「粘贴」
   - Y 向切片滑杆分层查看内部
   - 「合并减面并导出 STL」：贪婪网格化合并 + 顶点聚类减面，面数压到 **3 万以内**才允许导出二进制 STL
3. **提交质检**：整批模型自动跑检查，问题按 **致命/警告/提示** 分级：
   | 检查项 | 级别 |
   |---|---|
   | 网格不封闭（开放边） | 致命 |
   | 冠壁厚 < 1.5mm（沿内法线测量） | 致命 |
   | 桥体连接体截面积 < 9mm² | 致命 |
   | 法线朝向反转（有符号体积为负） | 警告 |
   | 悬空体素块（未与主体连通的孤岛） | 警告 |
   | 实体体素数异常偏少 | 提示 |
4. **复核员** 逐条点开问题，3D 视图自动定位到具体体素（红色标记 + 自动切片），逐条 **确认** 或 **驳回**（驳回必填原因，批次退回外协设计）。**存在未处理致命问题时整批不能放行**。
5. **放行** 后自动生成报告：每颗牙的体素数、面数、问题数、致命数。
6. **外协方** 只能看到退回清单（驳回的问题明细与原因），修复后由技师重新送检。

## 目录结构

```
shared/            前后端共用的核心算法（纯 JS）
  voxel.js         体素网格：分层/画笔/镜像/选区/连通域/壁厚/连接体面积/RLE 序列化
  mesh.js          贪婪网格化、顶点聚类减面、STL 导出、封闭性(T 接头感知)/法线检查
  qc.js            质检规则与分级
server/
  index.js         Express API：订单/模型/批次/复核/放行/报告，JSON 文件持久化
  smoke.js         端到端冒烟测试（node server/smoke.js）
src/
  components/VoxelEditor.svelte   three.js 体素编辑器（InstancedMesh + DDA 体素射线）
  components/TechnicianView.svelte  技师端
  components/ReviewerView.svelte    复核员端
  components/DoctorView.svelte      医生端
  components/OutsourcerView.svelte  外协端
```

## 技术要点

- 单牙 32³ 体素格，体素 0.25mm（单牙 8mm 见方），三层独立位图，RLE 压缩存储
- 编辑渲染用 InstancedMesh（每层一个），射线拾取用 Amanatides-Woo DDA 在体素格内走格，避免对数万实例做暴力求交
- 封闭性检查对贪婪合并产生的 T 型接头做了处理：先把每条边在共线顶点处剖分成原子段再统计覆盖次数，避免误判
- 壁厚沿表面体内法线方向步进测量，曲面边缘不会误报
- 角色数据隔离在服务端强制：医生按 `doctor` 过滤，外协方仅可访问 `status=returned` 的批次且只能看驳回明细

node server/index.js &   # 先起服务
