# 牧区围栏三维布点与档案加工系统

面向牧区围栏施工队的地块档案管理、三维布点、自动统计、审核与归档检索系统。

## 技术栈

- React 18 + Vite + React Router(Hash 路由)
- three.js(原生)——起伏地形、构件渲染、OrbitControls 漫游、TransformControls 平移/旋转手柄、HTML5 拖拽投放
- D3 v7 + SVG——俯视线形图、禁放区带状图、拐点标注、悬停提示、版本对比叠加
- Zustand + localStorage——档案、版本链、审核记录的本地持久化(无后端即可完整运行)

## 启动

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建
```

## 页面与业务流程

1. **档案列表**——录入草场编号、面积、围栏类型、牧户建档,自动生成 `WL-年月日-序号` 档案号
2. **三维布置**——从构件库拖入水泥桩 / 网片(以桩间线形表达)/ 大门 / 饮水点:
   - 左键拾取,TransformControls 手柄平移、旋转,Delete 删除
   - 桩位自动吸附起伏地面(`groundHeight`)
   - 触碰河流、道路、牲畜通道、已有围栏或越界即标红,弹出最近可放位置(0.5m 螺旋网格搜索)
   - 桩间距 3m / 5m 档位实时校验(容差 ±0.8m),规范:围栏高 1.1m、大门净宽 4m
   - 保存草稿版本或直接提交审核
3. **俯视统计**——D3+SVG 整体线形、禁放区、拐点(转角 >30°)与冲突点;自动统计桩数、网片米数(扣门宽)、门数、拐点坐标;输出物料清单与可打印施工说明;任选两个版本对比桩位增减与材料差额
4. **审核**——施工组长查看冲突复核表与桩距检查;通过即锁定版本,退回必须填写桩位冲突原因;完整审核记录随版本保存
5. **归档检索**——监理按牧户、年份、围栏类型、状态多条件检索;通过版本可归档;档案详情含版本链与全部审核记录

## 角色

顶栏切换:设计员(布点/改版)、施工组长(审核)、监理(归档检索)。已通过版本锁定,修改必须新建版本,历史版本只读可回溯。

## 目录

```
src/
  constants.js          业务常量(规范尺寸、状态、档案号工具)
  lib/geometry.js       地形、禁放区校验、最近可放点、桩距、链/拐点、统计、版本对比
  store.js              Zustand 持久化状态(档案/版本/审核流 + 示例地块)
  components/ThreeScene.jsx   three.js 场景(拖拽、拾取、手柄、吸附、冲突渲染)
  pages/                ArchiveList / Layout3D / Overview / Review / ArchiveSearch
```

数据存于浏览器 localStorage(key:`pasture-fence-store-v1`),清除浏览器数据即可重置,首次打开含一份已审核通过的示例档案。
