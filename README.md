# 定向越野跑姿骨骼动画制作与素材批次质检平台

原生 TypeScript + Web Components + SVG + D3，无框架、无打包器。工程数据保存在浏览器 localStorage。

## 运行

```bash
npm install        # 仅开发依赖（typescript / playwright 测试用）
npx tsc            # 编译 src/*.ts -> dist/
# 任意静态服务器，例如：
npx serve .        # 或 python -m http.server
# 打开 index.html 对应地址
```

## 七个界面

| 界面 | 说明 |
|---|---|
| 总览 | 工程/批次/问题统计与快捷入口 |
| 绑骨 | 导入拆件图（或占位件）挂到骨骼上，肩/肘/髋/膝/踝等关节拖拽定位；一套骨骼可挂多套选手皮肤共用动作 |
| 动画时间轴 | 打关键帧、拖动关键帧改时刻、每段插值在缓入缓出/线性间点击切换、关节拖拽直接改姿态、循环播放 |
| 数据对比 | D3 绘制步频与触地时长对比曲线，180–200 合格区间底色标出，超区间采样点红色标记；采样数据可编辑 |
| 批次质检 | 批次提交即自动检查（缺件=严重、绑点飞出画布=严重、帧数不足12帧=一般），复核员逐条确认/驳回，问题清零才能放行，有确认问题则退回供应方并附问题清单 |
| 教练端 | 只读，仅显示已放行动画与成绩汇总（角色切到"教练"后导航只剩此页） |
| 导出 | 序列帧 PNG 压缩包（内置极简 ZIP）、质检报告 HTML、工程 JSON 备份/恢复 |
