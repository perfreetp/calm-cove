# 青杠岭山区灌区 · 渠系平面图与档案加工系统

面向山区灌区管理所的渠系档案数字化工具：在扫描的原始渠系图上矢量化渠线与水工要素，
完成建档、加工、逐条审核、异常退回、多条件检索与带版本号导出归档。

技术栈：**React 19 + SVG + D3（d3-zoom）+ Zustand + Vite + TypeScript**，纯前端运行，无后端依赖。

## 运行

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 生产构建
npm run typecheck # TypeScript 类型检查
```

| 角色 | 建档编号 | 矢量化/改档 | 提交审核 | 审核通过/退回 | 归档 |

| 加工员 | ✅ | ✅ | ✅ | ❌ | ❌ |

## 完整业务流程

1. **建档编号**（左栏「渠系建档」→ `+ 建档`）
   选渠系等级（干渠/支渠/斗渠）、上级渠道，录入编号、名称、起止桩号、设计流量、建成年代；
   渠线走向通过「描线建档」工具在底图上逐点点击（≥2 点），终止桩号可按描线长度自动带入。
2. **导入扫描原图**（左栏「扫描原图」）
   拖入或选择 PNG/JPG/WebP/SVG，可多张叠加；支持不透明度、宽度、微调位置，用来与矢量线套合。
3. **矢量化要素**（工具栏 `闸门/量水堰/泵站/跌水/涵洞`）
   在地图上点击即落点，自动吸附到最近的渠道中心线并反算桩号；
   已落要素可拖拽改位置（自动重算桩号、生成新版本）。
4. **图层控制**：渠系等级、要素类型分别开关；另有扫描图、地形晕渲、渠道名称、桩号、退回段落等开关。
   **开关状态与视口位置写入 localStorage**，刷新后原样恢复。
5. **提交审核**（渠道详情卡 →「提交审核」），状态转为「待审核」。
6. **逐条核对**（「审核工作台」）
   左侧待审队列 → 勾选清单逐条核对桩号与平面位置（地图自动聚焦、高亮该渠道）；
   进度条实时统计 `已核 n/总数`；**未全部核对不能通过**。
7. **退回**：必须填写桩号段（起止 m）与退回原因，命中要素一并标红，地图上以红色虚线带标注该段；
   加工员在详情卡与审核台都能看到退回段落与原因。
8. **审核通过 → 归档冻结**：归档后渠道与要素全部只读，任何修改（改属性、拖动、新增要素）都会被拒绝。
9. **检索**（「档案检索」）：按渠系等级、要素类型、所属渠道、建成年代区间、档案状态、关键字多条件组合。
10. **导出**（「导出与版本」）：仅「已通过 / 已归档」档案可导出。
    - 渠系图 SVG：含水系、要素符号、桩号刻度、图例、标题栏，标题栏与文件名均带版本号；
    - 要素清单 CSV：逐要素含编号、类型、渠系、桩号、平面坐标、年代、状态、版本等，UTF-8 BOM 便于 Excel 打开。

## 大数据量表现（关键设计）

- 全灌区 **20,996 个要素 / 703 条渠道**，确定性种子生成（`src/data/worldgen.ts`）。
- **网格空间索引**（100 世界单位一格）只绘制视口内要素；视口外一律不建 DOM。
- **按缩放级别切换细节（LOD）**：
  | 缩放 | 级别 | 绘制内容 |
  | --- | --- | --- |
  | `< 1.15×` | 概览 | 只画干渠 + 主要泵站，符号抽稀 |
  | `1.15 – 3.6×` | 中景 | 干渠/支渠全要素 + 斗渠闸门/量水堰，标注去重 |
  | `≥ 3.6×` | 详图 | 全要素 + 闸门编号 + 量水堰刻度 + 桩号里程 |
- **屏幕恒定符号尺寸**：符号半径/字号按 `px / k` 换算，任何缩放下都保持同样的视觉大小。
- **屏幕空间抽稀与标注去重**：按像素格网挑代表要素，同格只保留一个编号，避免糊成一片。
- **rAF 合并重绘**：相机变化按帧节流；仅当视口桶或缩放档变化时才真正重排。
- 实测（1600×950 视口，连续平移+缩放 40 次）：帧间隔中位数 16.7 ms，P90 21.2 ms。

## 版本与留痕

- 要素每次改属性或拖动位置都会生成新版本，保存当时的坐标、桩号、全部属性与变更说明。
- 档案卡「历史版本」列表可任选两版（A/B）叠加：地图上并排显示两版位置、位移连线、
  位移距离与桩号差，下方表格逐项列出属性差异（旧值删除线 / 新值高亮）。
- 渠系图与要素清单导出均带 `V<日期>-<渠道数>C<要素数>F` 版本号，归档后版本不再变动。

## 操作快捷键

| 键 | 作用 |
| --- | --- |
| `V` / `P` / `M` | 选择 / 平移 / 量距 |
| `1`–`5` | 闸门 / 量水堰 / 泵站 / 跌水 / 涵洞 |
| 滚轮 | 以光标为锚缩放 |
| 拖动背景 | 平移；拖动要素 | 改位置（留痕） |
| `F` | 聚焦当前选中要素 |
| `Enter` / `Esc` | 完成描线 / 取消当前工具 |
| `?` | 显示操作速查 |

## 目录结构

```
src/
  types.ts              领域类型与枚举、配色、标签
  store.ts              Zustand 全局状态：图层、相机、选择、审核标记、业务动作、localStorage 持久化
  data/worldgen.ts      确定性渠网生成（3 干渠 / 72 支渠 / 628 斗渠）+ 网格空间索引 + 扫描图定义
  lib/geo.ts            折线几何、桩号换算、最近点吸附、比例尺
  lib/exporters.ts      带版本号的 SVG 图纸与 CSV 清单导出
  map/MapView.tsx       D3 zoom + SVG 渲染主体（渠线、要素、退回带、版本叠加、绘制预览）
  map/pick.ts           LOD 规则、屏幕↔世界坐标、点选
  map/symbols.ts        五类要素的平面图符与量水堰刻度
  map/raster.ts         地形晕渲与复古扫描件程序化生成
  components/           渠系树、图层、扫描图、档案卡、统计、审核台、检索、导出、工具栏
```
