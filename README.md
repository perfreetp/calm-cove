# AURIS · 耳模定制云平台

基于 **React 18 + TypeScript + WebGL2** 的定制耳模曲面建模与门店运营系统。验配端完成耳印扫描点云导入 / 手动摆点建模、实时改形、曲率风险识别、等距/自适应壁厚偏置与下料展开图导出；管理端完成门店、验配师账号、材料库存交期管理与按门店的运营统计。

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173
npm run typecheck  # 仅类型检查
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建
```

需要支持 WebGL2 的浏览器。所有数据保存在浏览器 `localStorage`（键 `auris.db.v1`），首次进入自动生成演示数据；「工作台」底部可重置演示数据。

右上角「身份」下拉可切换验配师 / 审核员 / 管理员，侧栏随角色变化。

## 验配端（建模工作室）

路由 `/#/studio/:orderId`，三栏布局：输入与参数 / 三维视口与下料图 / 曲率分析与版本。

1. **耳印输入**
   - 导入点云文件（`.xyz/.csv/.pts/.txt`，每行 `x y z`，支持 `#` 注释）。点云按 9 × 12 控制网格分桶拟合，生成耳甲腔到耳道的曲面。
   - 「使用示例扫描数据」注入确定性合成扫描（带噪声）。
   - 也可直接在三维视口点击控制点手动摆点。
2. **实时改形**
   - 视口中拖动球形控制点：径向拖动改变耳模外扩、轴向拖动调整耳道走向；投影后的屏幕位移通过控制点局部基（法向 / 耳道切向）反解成毫米偏移。
   - 空白处拖动旋转，`Shift`+拖动平移，滚轮缩放；工具栏可自动旋转、复位视角、开关控制网格。
   - 每次拖动后网格以约 130×140 分辨率重建（约 40 ms），并同步更新曲率与壁厚。
3. **曲率视图**
   - 「曲率」模式按 `K / 阈值` 着色，超过阈值区域标红并脉动提示，右上角图例给出阈值刻度。
   - 右侧「危险区域」按连通簇列出超限位置（深度百分比 + 钟点方位 + 超出百分比），点击可定位到最近控制点。
   - 阈值滑块可实时调整（0.45–1.20 mm⁻¹，默认 0.67）。
4. **壁厚偏置**
   - 0.8 / 1.2 / 1.6 / 2.0 mm 四档等距偏移，外壳与内壁双层网格 + 端部封边。
   - 「自适应偏置」开启后按曲率加权加厚（最大 ×1.55），并以 `0.78/K` 限制避免内壁自交；「壁厚」视图显示实测厚度分布。
5. **下料展开图**
   - 按环向弧长与子午线弧长做真长展开（1 单位 = 1 mm），带贴合边止口、泄压孔 Ø1.3、耳道接口与 10 mm 校准标尺；曲率超限处用红色虚线圈标注。
   - 画布视图可叠加曲率热度与尺寸标注，一键导出 **SVG**（毫米单位，可直接打印/下料）。
6. **方案版本**
   - 「保存版本」把当前控制点坐标（9×12）、壁厚档位、是否自适应、阈值与曲率指标写入新版本，可附说明。
   - 版本列表可点击回溯；提交审核后当前版本锁定，需另存新版本。

## 审核端

- `/#/review` 审核队列（待审核 / 已退回 / 已通过），显示曲率峰值与阈值对比、退回次数、等待时长与 SLA。
- `/#/review/:orderId` 同步展示曲率三维预览与下料展开图、合规检查（曲率合规 / 壁厚匹配 / 超限面积 / 下料图完整）、方案参数、历史退回与完整操作记录。
- 「退回修改」必须填写原因（≥8 字，可点选常用原因），写入订单退回记录并计入退回次数；「审核通过」进入已下单并按材料扣减 1 只库存。

## 运营后台

- **门店管理**：门店卡片与对比表，含订单量、平均退回次数、准交率、平均壁厚、验配师人数。
- **账号与角色**：验配师 / 审核员 / 管理员，角色与门店归属、在职状态、完成量与审核工作量。
- **材料规格**：规格、硬度、颜色、交期、库存水位、单价；库存低于 200 只安全线时页面顶部与侧栏角标提示补货，支持补货入库。
- **统计与导出**：
  - 订单总量、平均退回次数、一次通过率、准交率；近 N 天趋势（交付 / 新建 / 退回）。
  - 壁厚档位分布环形图、门店订单量与退回率、验配师完成量、状态分布。
  - 曲率超限列表（订单 / 版本 / 峰值 / 超出百分比 / 壁厚）。
  - 导出 **近 30 天订单明细 CSV** 与 **曲率超限列表 CSV**。

## 订单状态流转

`待建模 → 待审核 → 已下单 → 已交付`，任一审核节点可退回为 `已退回`（保留退回次数）。每次流转在订单 `events` 中记录操作人与时间，建模页与审核页均可查看完整时间线。

## 目录结构

```
src/
  lib/geom.ts      参数化耳模曲面、控制点插值、主曲率、壁厚、点云拟合
  lib/unroll.ts    真长展开（弧长保持）、下料图几何
  lib/export.ts    SVG 下料图、CSV 导出
  lib/seed.ts      演示数据（6 门店 / 14 账号 / 6 材料 / 28 单）
  lib/stats.ts     门店、壁厚、验配师、曲率超限等统计口径
  webgl/EarRenderer.ts  WebGL2 渲染器（双层外壳、曲率/壁厚着色、控制点拾取与投影）
  components/SheetView.tsx  下料图画布
  components/Preview3D.tsx  审核端三维预览
  pages/           工作台、订单、工作室、审核、门店、账号、材料、统计
  store.tsx        全局状态与业务动作（localStorage 持久化）
```

曲面构建是纯 CPU 计算 + 一次性上传缓冲：控制点权重按网格分辨率缓存，逐顶点解析一阶/二阶导数求主曲率（`kMax = |H| + √(H²−K)`），再做一次 3×3 松弛抑制单点采样噪声。
