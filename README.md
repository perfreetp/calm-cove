# 压力衣曲面建模与考核工作台

面向康复治疗师培训机构的烧伤压力衣（烧伤弹力衣）曲面建模、缝份展开与技能考核系统。
前端使用 Svelte 5 + Vite，所有图形绘制在 **Canvas 2D + OffscreenCanvas** 离屏画布上完成。

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 5173）
npm run build    # 生产构建到 dist/
npm run preview  # 预览生产构建
```

浏览器需支持 `OffscreenCanvas`（Chrome/Edge 69+、Firefox 105+、Safari 16.4+）。
检测不到时自动回退到普通 `<canvas>`，功能不受影响，顶栏会显示「离屏回退模式」。

## 教学流程

### 教师端

1. **任务与截止**：新建任务 —— 填写肢体部位、围度测量表（位置 / 围度 / 标记点）、
   瘢痕位置示意图（起止 mm、程度、说明）、压力档位区间、面料、曲率突变阈值、截止时间。
   测量表的 `围度 ÷ 2π` 自动成为参考轮廓半径，用于学员端比对。
2. **班级进度**：每位学员的提交状态、作答次数、自动分 / 最终分、RMS、超限区段、重做提升值；
   右侧自动列出「需要关注」（待复核、补交、低分）与本任务错误分布。
3. **复核打分**：打开任一提交，在参考轮廓叠加、曲率梳、偏差带上逐项核对；
   可一键把某个超限区段写入评语，追加扣分（0–100，支持快捷档 2/4/6/8/10），
   最终分 = 自动分 − 教师扣分。已复核可撤销。
4. **常见错误**：按「每位学员 × 每个任务最近一次」统计四类错误（轮廓偏差、曲率突变、
   缝份自交、压力档位），并给出每位学员的错误画像。
5. **成绩单**：按学员 × 任务汇总最近成绩与作答次数，补交单独计数；
   可导出 CSV（Excel 直接打开，含全部重做历史）或打印。

### 学员端

1. **建模**：左栏给出测量表、瘢痕示意、面料与工艺参数；
   画布上拖动控制点调整样条轮廓，双击空白处加点、右键删点、滚轮缩放、拖空白平移。
   实时显示曲率梳（屏幕法线方向）与悬停处的 `κ`、曲率半径 `ρ`；
   `|dκ/ds|` 超过任务阈值处标黄并提示区段数。
2. **缝份与展开**：缝份量默认按面料弹性系数换算 `基准缝份 × (1 + k)`；
   可手动改，系统提示偏离程度。偏移线实时做自交检测，交点用红叉标出。
   下方为展开下料图：长度沿经线弧长，宽度为 `2πr + 2×缝份`，显示面积与周长。
3. **提交**：实时预评分（轮廓贴合 60 + 曲率平滑 20 + 缝份展开 10 + 压力档位 10）。
   提交后进入结果页：最终成绩、分项条、教师评语、**偏差 > 5 mm 的区段表**，
   以及带红色偏差带的复核画布；曲率突变区段单独成表。
4. **重新作答**：从测量表重建控制点，历史成绩与评语全部保留，作答次数递增。
5. **导出**：下料图 SVG（1:1，`width/height` 直接用 mm，打印 100% 即实物尺寸）、
   PNG、打印窗口（A4 横向、自动提示超幅）、单次考核报告 HTML。

## 评分口径

| 项目 | 分值 | 计算方式 |
| --- | --- | --- |
| 轮廓贴合 | 60 | `0.6 × (1 − RMS/8) + 0.4 × (1 − 超限区段数/6)`，再乘 60 |
| 曲率平滑 | 20 | `20 − 2.5 × 曲率突变区段数`（下限 0） |
| 缝份展开 | 10 | 与弹性换算值差值 ≤0.5 / ≤1.5 / ≤3 mm 得 10 / 8 / 6，其余 3；存在自交封顶 3 |
| 压力档位 | 10 | 落在档位区间 10，差 3 mmHg 内 6，否则 2 |

- **RMS**：学员轮廓与教师参考轮廓（由测量表生成）在等距采样点上的均方根偏差。
- **5 mm 阈值**：`|Δr| > 5 mm` 的连续采样区间合并为一个「错题区段」，记录起止、最大偏差与方向。
- **曲率突变**：`|dκ/ds|` 超过任务阈值处标记；相邻区段在图上合并显示、在表中逐条列出。
- **缝份自交**：偏移折线非相邻段求交并去重；自交数量直接进入「缝份展开」与错误统计。
- **压力估算**：拉普拉斯定律 `P(mmHg) = 7500.6 × T(N/mm) / r(mm)`，仅用于档位校核，
  不替代实物压力测试。

## 导出

- **成绩单 CSV**：UTF-8 BOM，Excel 中文不乱码；含明细表 + 班级汇总两段。
- **下料图 SVG**：`width="…mm"`，1:1；含 10 mm 方格、净样虚线、裁剪实线、对位标记、
  长度/宽度尺寸标注、打印说明；幅面超过 A4 横向可打印宽度时在图上与界面同时告警。
- **打印窗口**：嵌入 PNG 并自动 `window.print()`，页脚注明面积、周长与超幅提示。
- **考核报告 HTML**：单次提交的完整评分构成、错题区段、曲率突变、工艺参数与教师评语。

## 数据

- 全部数据存于 `localStorage`（键 `burn-garment-studio.v1`），刷新、重启浏览器均保留。
- 顶栏「重置数据」恢复种子数据：7 名学员、3 个任务、10 份提交，
  覆盖高分、曲率突变、偏差超限、缝份自交、压力不达标、补交等教学案例。
- 截止时间之后的提交自动标记「补交」，不影响自动评分，但成绩单与进度表中单独展示。
