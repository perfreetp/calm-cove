# 路况播报数字人 · 动画制作与审片系统

基于 **Vue 3 + Canvas 2D + OffscreenCanvas(Web Worker)** 的交通路况播报数字人动画制作与审片一体化系统。

## 运行

```bash
npm install
npm run dev    # 默认 5173 端口，被占用时自动递增
npm run build  # 生产构建
```

## 功能地图

### 动画制作（左栏 + 中央画布 + 底部时间轴）
- **拆件导入**：部件库支持导入 PNG/WebP 拆件（锚点默认取中心，可改）；内置演示角色「主播·小畅」为程序化生成的全套拆件（躯干/头/双眼/9 个音素嘴型/双臂双手）。
- **骨骼绑定模式（①）**：双击空白处在选中骨骼下新增子骨骼，拖动节点摆位置；左栏可改父子关系、挂载部件、**关节角度限制**（画布上显示限制扇形，超限自动钳制）。
- **动画模式（②）**：拖骨骼末端旋转、Shift+拖动移动，松开即在当前帧自动打关键帧。
- **时间轴**：位置X/Y、旋转、缩放X/Y、不透明度**六条独立属性轨道**；关键帧拖动改帧、右键删除；插值支持**线性 / 缓入缓出 / 贝塞尔手柄**（选中关键帧后弹出曲线编辑器，双手柄可拖）。
- **口型**：9 音素表（sil/A/E/I/O/U/M/FV/L）点击即对齐到当前帧；支持播报词文本一键转音素序列（按字占帧数铺开）。
- **循环轨道**：眨眼（短促闭合脉冲，duty 可调）、呼吸（整周期正弦）自动补间，周期/范围/开关可配，可自定义新增。

### 预览与导出（右栏）
- **预览**：`transferControlToOffscreen` 把画布移交 Worker，播放渲染完全不阻塞主线程；不支持 OffscreenCanvas 时自动回退主线程。
- **导出**：Worker 逐帧渲染 PNG 序列帧，自实现 ZIP(STORE) 打包，内含 `manifest.json`（帧号、文件名、时间码），可按帧区间导出。

### 审片流转（右栏 · 审核/对比/统计）
- **版本**：每次「提交审核」快照当前骨骼+轨道+口型生成 V1/V2/…；**有未处理批注时禁止提交下一版**。
- **批注**：审核人指定帧+关节，可「画面打点」取坐标，写清哪一帧哪个关节不对；批注点渲染在画面当前帧上，点击批注跳转定位（帧+选中关节）。
- **回复**：制作方逐条回「已改 / 驳回」并填写说明；全部处理完才解锁下一版提交；审核人可点「审核通过」。
- **对比**：任选两个版本，同一帧滑杆并排渲染对比。
- **统计**：按播报模板 / 主播角色 / 时间段筛选审片记录，输出**一次通过率**、**平均返工轮次**、未处理批注数。

## 代码结构

```
src/
  engine/            # 与 UI 无关的纯逻辑（主线程与 Worker 共用）
    curves.js        # 线性/缓入缓出/贝塞尔插值（牛顿迭代解 x→t）
    rig.js           # 骨骼 FK 求解、关节角度钳制、循环轨道采样
    render.js        # 单帧渲染（演播室背景+角色+骨骼+批注点）
    lipsync.js       # 音素轨道采样、中文播报词→音素
    demoCharacter.js # 程序化演示角色拆件 + 默认装配/循环轨道
    zip.js           # 极简 ZIP(STORE) 写入器（CRC32）
    exporter.js      # 序列帧导出 + 清单生成
  workers/renderWorker.js  # OffscreenCanvas 渲染 Worker（预览/导出）
  store.js           # 响应式状态、版本/批注流转、统计、localStorage 持久化
  components/        # LibraryPanel / StageCanvas / TimelinePanel / CurveEditor /
                     # PreviewPanel / LipSyncPanel / ExportPanel / ReviewPanel /
                     # ComparePanel / StatsPanel
```

数据持久化在 `localStorage`（键 `traffic-anchor-studio-v1`），顶栏「重置演示数据」可恢复出厂演示工程（含两个历史版本与批注，便于直接体验审片/对比/统计）。
